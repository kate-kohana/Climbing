# Climbing
Web app for climbing gym

 Требования к продукту
5.1. Модель карточки трассы (оцифровка физической)
Общие поля:
•	Тип: болдер / трудность
•	Цвет
•	Дата накрутки
•	Автор накрутки
•	Фото (1–3)
•	Статус: активна / снята
Для болдера (аналог цветного стикера):
•	Цвет стикера = уровень (белый, жёлтый, зелёный, синий, красный, чёрный — по шкале зала)
•	Название (опционально, часто нет)
Для трудности (аналог бумажной карточки):
•	Название
•	Категория (5a–8a)
•	Уровень нависания (вертикаль / нависание / сильное / потолок)
•	Тип зацепов (полки, щипцы, моно, рельеф)
5.2. Функциональные требования (FR)
FR-1. Авторизация и роли
•	Роли: гость (просмотр), скалолаз, накрутчик, админ.
FR-2. Каталог трасс
•	Список карточек, фильтры: тип, цвет, категория, нависание, автор, дата, статус.
FR-3. Карточка трассы (страница)
•	Все поля + отзывы + статистика пролазов.
FR-4. Отметка пролаза
•	«Пролез» (redpoint / flash / onsight) / «Не пролез», дата.
FR-5. Отзывы
•	Текст (до 500 символов), оценка сложности (1–5), отметка «ключевой момент».
FR-6. Рекомендации
•	По категории (±1), по стилю, по типу зацепов, исключая пройденные.
FR-7. Админ-панель и статистика 
FR-8. Управление трассами (админ)
•	Добавить / редактировать / снять трассу.
•	Массовое добавление (загрузка списка).
